# LEXORA

LEXORA is Zyph Legal LP's law practice workspace, built with React, TypeScript, Vite, Supabase, and an Express API deployed on Vercel.

## Local development

1. Install Node.js and run `npm install`.
2. Copy `.env.example` to `.env.local` and set Supabase keys. Keep `SUPABASE_SERVICE_ROLE_KEY` server-only.
3. Run `npm run dev` for the web app and `npm run dev:api` for the local API.

See [SUPABASE_SETUP.md](SUPABASE_SETUP.md) to create a fresh LEXORA database and [BACKUP_SETUP.md](BACKUP_SETUP.md) to configure independent scheduled backups.
